# Frontend Backend

这个目录用于存放前后端协作边界与前端开发规范。

适合记录：

- API 归属边界
- 请求与响应结构
- 字段名与类型约束
- 联调注意事项
- 前端代码与样式规则
- 工具函数复用约束

当前已拆分出的核心说明：

- `boundary.md`
- `frontend-rules.md`
- `frontend-utils.md`
- `component-library.md`
- `theme-classnames.md`
- `instance-frontend-sync.md` — 实例模式下前端 dist 更新流程（改了前端代码后如何让实例生效，避免"新页面空白"）
