# PMocker M5 前端页面阶段实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 9 个项目管理后端模块构建完整前端页面（23 页面 + 9 API 封装文件 + menu.yaml 更新），遵循 gva/aiDoc 规范。

**Architecture:** 前端页面放在 `gva/web/src/view/pmocker/<mod>/`，API 封装放在 `gva/web/src/api/pmocker/<mod>.js`。所有页面使用 Element Plus + UnoCSS 语义 token，特殊视图使用 echarts/vuedraggable/el-tree 等项目已有依赖。菜单由后端 menu.yaml 驱动，component 字段更新为 `view/pmocker/<mod>/<page>`。

**Tech Stack:** Vue 3.5 + Element Plus 2.13 + UnoCSS + echarts 5.5 + vue-echarts 7 + vuedraggable 4 + vue-router 4

## Global Constraints

- HTTP 请求统一走 `@/utils/request`（aiDoc 硬约束）
- 文件名 kebab-case，组件名 PascalCase，变量名 camelCase
- `v-model` 一律用 `defineModel()`（Vue ≥ 3.4）
- 图标用全局 `<svg-icon icon="lucide:xxx" />`，不用 `el-icon` / `ep:` 图标集
- 业务页面用 Element Plus + UnoCSS 语义 token（`bg-container`/`text-base-text` 等），禁止硬编码颜色
- API 封装补全 JSDoc，函数命名 `动词 + 名词`
- 查询区用 `gva-search-box`，表格区用 `gva-table-box`
- 跨组件通信用 `@/utils/bus`（事件总线）
- 提交粒度：一个 Task 一个 commit
- 后端 API 路由前缀：`/requirement`、`/scope`、`/schedule`、`/cost`、`/risk`、`/issue`、`/eps`、`/deliverable`、`/change`

## 已有类型参考

后端 API 响应统一格式：`{ code: 0, msg: "成功", data: {...} }`

gva 前端 request.js 返回完整 response，页面层检查 `res.code === 0`。

el-table 列模板参考 `gva/web/src/view/superAdmin/user/user.vue`。
API 封装参考 `gva/web/src/plugin/email/api/email.js`。
页面组件参考 `gva/web/src/plugin/email/view/index.vue`。

  <div>

<script setup>
import { ref, reactive } from 'vue'
import { ElMessage, ElMessageBox } from 'element-plus'
import {
  getRequirementList,
  createRequirement,
  updateRequirement,
  deleteRequirement,
  submitRequirementReview,
  approveRequirement,
  rejectRequirement
} from '@/api/pmocker/requirement'

defineOptions({ name: 'PmockerRequirementList' })

const searchInfo = ref({})
const tableData = ref([])
const page = ref(1)
const pageSize = ref(10)
const total = ref(0)
const dialogVisible = ref(false)
const dialogTitle = ref('')
const formRef = ref(null)
const dialogType = ref('add')

const form = reactive({
  ID: null,
  title: '',
  description: '',
  priority: 'medium'
})

const rules = {
  title: [{ required: true, message: '请输入需求名称', trigger: 'blur' }],
  priority: [{ required: true, message: '请选择优先级', trigger: 'change' }]
}

const formatDate = (dateStr) => {
  if (!dateStr) return ''
  return new Date(dateStr).toLocaleString('zh-CN')
}

const priorityType = (priority) => {
  const map = { high: 'danger', medium: 'warning', low: 'info' }
  return map[priority] || 'info'
}

const statusType = (status) => {
  const map = { draft: 'info', reviewing: 'warning', approved: 'success', rejected: 'danger' }
  return map[status] || 'info'
}

const statusLabel = (status) => {
  const map = { draft: '草稿', reviewing: '评审中', approved: '已批准', rejected: '已驳回' }
  return map[status] || status
}

const getTableData = async () => {
  const params = { page: page.value, pageSize: pageSize.value, ...searchInfo.value }
  const res = await getRequirementList(params)
  if (res.code === 0) {
    tableData.value = res.data.list || []
    total.value = res.data.total || 0
  }
}

const onSubmit = () => {
  page.value = 1
  getTableData()
}

const onReset = () => {
  searchInfo.value = {}
  page.value = 1
  getTableData()
}

const openDialog = (type, row) => {
  dialogType.value = type
  dialogTitle.value = type === 'add' ? '新增需求' : '编辑需求'
  if (type === 'edit' && row) {
    Object.assign(form, row)
  } else {
    Object.assign(form, { ID: null, title: '', description: '', priority: 'medium' })
  }
  dialogVisible.value = true
}

const handleSave = async () => {
  if (!formRef.value) return
  await formRef.value.validate(async (valid) => {
    if (!valid) return
    const api = dialogType.value === 'add' ? createRequirement : updateRequirement
    const res = await api(form)
    if (res.code === 0) {
      ElMessage.success(dialogType.value === 'add' ? '添加成功' : '更新成功')
      dialogVisible.value = false
      getTableData()
    }
  })
}

const handleDelete = (row) => {
  ElMessageBox.confirm('确认删除该需求吗？', '提示', { type: 'warning' })
    .then(async () => {
      const res = await deleteRequirement({ ID: row.ID })
      if (res.code === 0) {
        ElMessage.success('删除成功')
        getTableData()
      }
    })
    .catch(() => {})
}

const handleSubmitReview = async (row) => {
  const res = await submitRequirementReview({ ID: row.ID })
  if (res.code === 0) {
    ElMessage.success('已提交评审')
    getTableData()
  }
}

const handleApprove = async (row) => {
  const res = await approveRequirement({ ID: row.ID })
  if (res.code === 0) {
    ElMessage.success('已批准')
    getTableData()
  }
}

const handleReject = async (row) => {
  ElMessageBox.prompt('请输入驳回原因', '驳回', { type: 'warning' })
    .then(async ({ value }) => {
      const res = await rejectRequirement({ ID: row.ID, reason: value })
      if (res.code === 0) {
        ElMessage.success('已驳回')
        getTableData()
      }
    })
    .catch(() => {})
}

getTableData()
</script>

  if (!chartRef.value) return

  const nodes = (data.tasks || []).map(t => ({
    id: String(t.ID),
    name: t.title,
    itemStyle: { color: data.criticalPath?.some(cp => cp.ID === t.ID) ? '#f56c6c' : '#409eff' },

  }))

  const links = (data.dependencies || []).map(d => ({
    source: String(d.srcID),
    target: String(d.dstID)
  }))

    tooltip: {},
    series: [{
      type: 'graph',
      layout: 'force',
      data: nodes,
      links,
      roam: true,
